# ハンドオフ: Rengoku（煉獄）会員アプリ — デザイン説明書

## 1. 概要
少人数・招待制チーム専用の会員アプリ「Rengoku」のデザインです。メンバーが見るのは、毎日の成績（今日の利益・BET 履歴）、毎日 0:00 に締めて 24 時間以内に送金する精算、紹介、そして運営 3 名からのお知らせ（サロン）です。
スマホ（PWA としてホーム画面に置いて使う）が主な対象で、PC と iPad にも対応します。

**デザインの方向「2a 篝火の紋」**：夜の闇に灯る篝火。炭色の地に、細い金線と炎のグラデーションを合わせた上品な見た目です。ゲーム風の丸い文字や厚い板は使いません。
⚠ 特定の作品（鬼滅の刃）のキャラクター・名前・家紋・羽織の柄は使っておらず、似せてもいません。実装でも足さないでください。

## 2. このファイルについて
`design/` の HTML は**デザインの見本（プロトタイプ）**で、そのまま本番に使うコードではありません。
実装するときは、使っている環境（React / Next.js / Vue など）の書き方で**作り直して**ください。まだ環境が無ければ、PWA に向いた構成（例: Next.js + CSS 変数）を選んでください。

見本の開き方: `design/Rengoku.dc.html` をブラウザで開きます（同じフォルダの `support.js` が必要です）。キャンバスを動かしたり拡大・縮小したりして見られます。
- `Rengoku.dc.html` … 全画面をまとめた見本のボード
- `Rengoku Top.dc.html` … TOP 画面の部品（画面の幅に合わせて伸び縮みします）
- `Rengoku Home.dc.html` … ダッシュボードの部品（スマホは 1 列、iPad は 2 列）

## 3. 仕上がりの精度
**高精度（hi-fi）**です。色・文字・余白・動きは最終の値です。このとおりに再現してください。
数字はすべて架空の見本です。本番では API の値に差し替えます。

## 5. 動きとふるまい
| 何が | どう動くか |
|---|---|
| ボタンを押した時 | 押した瞬間に影の深さ分（4px）沈み、下の硬い影 `0 4px 0` が 0 になる（80ms）。離すと 120ms で戻る |
| HUD の丸ボタンを押した時 | 面が `rgba(255,200,61,.12)` に変わる |
| 今日の利益 | 画面を開いて 0.5 秒後から、0 → 実際の値まで 1.3 秒で数字が転がる（ease-out の 3 乗）。止まったら 0.7 秒だけ文字色が `#FFF3B0` になり、`0 0 30px rgba(255,200,61,.9)` で強く光る |
| 締め・支払い期限 | 1 秒ごとに減る。表示は `HH:MM:SS` |
| 火の粉 | 直径 2〜5px。色は `#FF8A1F`（約 6 割）と `#FFC83D`。1 個あたり 7〜15 秒かけて下から上へ昇り、左右に ±35px 流れる。光は `0 0 (直径×3)px (直径×0.8)px rgba(255,110,31,.5)`。数はスマホで 8〜16 個 |
| 炎のゆらぎ | `rgFlicker`: scaleY 1 → 1.08 → .95、不透明度 .8〜1、3〜3.4 秒で往復 |
| オンラインの点 | `rgPulse`: 0 → 9px の緑の輪が広がって消える。1.8 秒で繰り返す |
| 画面の切り替え | 横にスライドしながら、炎がうっすらよぎる程度（約 250ms） |
| 動きを止める設定 | オンにすると、火の粉・ゆらぎ・数字の転がり・登場の動きを止める。OS の `prefers-reduced-motion` にも従う |
| 音・振動 | 初期設定はどちらもオフ。オンの時、押した瞬間に `navigator.vibrate(10)` と短い「カチッ」の音。お知らせでは音を鳴らさない |

```css
@keyframes rgFlicker{0%{transform:scaleY(1) scaleX(1);opacity:.85}50%{transform:scaleY(1.08) scaleX(.97);opacity:1}100%{transform:scaleY(.95) scaleX(1.03);opacity:.8}}
@keyframes rgPulse{0%{box-shadow:0 0 0 0 rgba(91,209,139,.7)}100%{box-shadow:0 0 0 9px rgba(91,209,139,0)}}
@keyframes rgBlink{0%,100%{opacity:1}50%{opacity:.25}}
@keyframes rgRise{0%{opacity:0;transform:translateY(46px) scale(.9);filter:blur(10px)}60%{opacity:1;filter:blur(0)}100%{opacity:1;transform:none;filter:blur(0)}}
@keyframes rgBlade{0%{background-position:-60% 0}100%{background-position:160% 0}}
```

## 6. 精算の言葉づかい（大切）
- とても丁寧に、責めない言い方にする。「〜をお願いいたします」「お手数ですが」を使う。
- 期限を過ぎた時：「お手すきの時にご送金をお願いいたします。ご不明な点はサロンの運営までお気軽にどうぞ。」のような**案内だけ**を出す。止める操作は運営が手で行い、アプリからは止めない。
- 利益がマイナスの日：「本日のチャージはありません」。
- 送る金額は「画面に出た金額ちょうど」（端数のセントで本人を見分けるため）。

残り時間は、画面を開いた時にサーバーの時刻と合わせ、そのあとは手元で 1 秒ずつ数える。

## 8. デザイントークン
すべて `rengoku-tokens.css` にあります（`--rg-*`）。このあと作る運用者向けの「マスター画面」にも同じものを使います。主なもの:

**色**
- 地: `--rg-ink #140A06`（最も深い）/ 画面 `#110805` / ページ `#0C0604`
- カードの面: `rgba(26,13,8,.82)`、主役のカードは `rgba(60,24,10,.9) → rgba(24,12,7,.92)`
- 金: `--rg-gold #FFC83D`、文字用の金 `--rg-gold-text #F2C463`、英字ラベル `--rg-label-gold #C9A56A`、金の影 `#D98A0A`

- 文字: 本文 `#F6EAD6`、ボタンの文字 `--rg-cream #FFF4E2`、補助 `#A89078`、さらに淡い `#9C8670`
- 結果: プラス `#F2C463` / マイナス `--rg-lose #7FB2FF`（赤は主役の色なので、損失には使わない）/ 成功 `--rg-ok #5BD18B`
