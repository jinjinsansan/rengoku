# ハンドオフ: Rengoku マスター画面（運用者向け）

## 1. 概要
打ち手（1 名）とオーナーの 2 名だけが使う操作画面です。ライブのバカラを見ながら「卓・PLAYER か BANKER か・額」を押すと、受け子（メンバーの PC、15〜18 台）に同時に BET が配られます。BET の締め切りまで十数秒しかない中で押す画面です。
見た目は会員アプリと同じ「2a 篝火の紋」ですが、**操作の速さと読みやすさが最優先**です。火の粉は PC で 6 個だけにし、炎のゆらぎは使いません。

## 2. このファイルについて
`design/Rengoku Master.dc.html` は**デザインの見本**です。実装は、今のマスター画面（サーバーが出す HTML と JavaScript）の見た目を、この説明書の数値で作り直す形で行ってください。
見本の PC 画面は実際に操作できます。卓を押す・チップを選ぶ・P/B を押す（受付票が出る）・取消（締め切り 5 秒前まで）・P⇄B・⇄TIE・緊急 STOP（確認つき）を試せます。残り秒は 18 秒から 1 秒ずつ減り、締め切ったら 3 秒後に次の回へ進みます。受付票の結果は見本の固定値です。
精度は**高精度（hi-fi）**です。共通のトークンと会員アプリの決まりは `README.md` と `rengoku-tokens.css` にあります。マスター画面用の値は `--rg-m-*` として追加しました。

## 3. 色の決まり（大切）
- 罫線と P/B のボタンの中だけは、**バカラの慣習の色**: P = 青 `#3E7BF0`（文字は `#6FA0FF`）、B = 赤 `#E0393E`（文字は `#FF6B6E`）、T = 緑 `#2FAE6A`（文字は `#4FCB8A`）。
- ほかの場所の赤（深紅）は、装飾と緊急 STOP だけに使います。
- 損失は青 `#7FB2FF`、利益は金 `#F2C463`。
- 状態の色: 成立 `#5BD18B`、不成立 `#FF6A3D`、締切待ち `#7D6F64`（文字は `#B3A496`）、応答なし `#F2C94C`、締切間近・段のズレ `#FFB04A`。

## 4. PC（1440×900）の組み立て
- 地は `#0E0705`。上から順に:
  - **A 上の固定バー**（60px）
  - **B 集計のタイル**（上下の余白 10px）
  - **本体**：3 列のグリッド `270px | 1fr | 510px`、間隔 12px、左右と下の余白 12px
- **パネル共通**：縁 1px `rgba(255,200,61,.22)`、角丸 12px、面 `rgba(20,10,6,.75)`
  - 見出し：英字ラベル（Cinzel 11px / 字間 .24em / `#C9A56A`）+ 明朝 700 15px
- 1440 より広い時は中央の列だけが広がります。1280 では受け子の列を 2 列にしてください。

  - **緊急 STOP**：高さ 40px、左右の余白 18px、角丸 10px、面 `--rg-m-grad-stop`、影 `inset 0 0 0 1px rgba(255,190,170,.5), 0 3px 0 #0A0503`、明朝 700 15px。押すと 3px 沈む

### E. 操作の面（いちばん大事）

- 余白 14px 18px 16px、行の間隔 12px

- **額のチップ**：段どおり / $1 / $5 / $10 / $25 / $50 / $100。間隔 8px
  - 大きさ：高さ 40px、最小の幅 62px、角丸 20px
  - 文字：Saira 700 17px（「段どおり」だけ明朝 14px）

  - 選ばれている：面 `--rg-m-chip-on-bg`（金の板）、文字 `#140A06`、縁 `#FFE9A8`、外に 3px の光の輪 `rgba(242,196,99,.22)`

- **台ごとの札**：高さ 24px、角丸 5px、縁 1px、余白 0 8px、Saira 600 14px。中身は「印 + 名前 + 額」
  - 色は 3 章の状態の色。面は 12〜16% の透明度、縁は 50〜60%

- **理由の行**：不成立と応答なしの台ごとに 1 行
  - 12px、行の高さ 1.55、余白 6px 10px、角丸 6px
  - 面：不成立 `rgba(255,106,61,.08)` / 応答なし `rgba(242,201,76,.07)`

## 6. 動き
| 何が | どう動くか |
|---|---|
| P/B を押した時 | 6px 沈む（60ms）+ 光の輪（700ms）+ 10ms の振動 |
| 受付票 | 押した直後は全台「締切待ち」で出し、結果が届いた台から色を変える |
| 全台の結果がそろった時 | 900ms だけ光る（緑か炎色） |
| 残り秒 | 1 秒ごとに数字・輪・色を変える |
| 火の粉 | PC で 6 個、10〜18 秒で昇る。動きを止める設定でなくす |
| 炎のゆらぎ | 使わない |
