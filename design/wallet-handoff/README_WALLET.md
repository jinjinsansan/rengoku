# ハンドオフ: Rengoku 資産の画面（BTC・ETH で運用する会員のため）

## 1. 概要
コピートレードに BTC・ETH で参加している会員が、次の 2 つを**分けて**体感できる画面です。
- 「トレードで増えた枚数」（打ち手の成果）
- 「値上がり益」（相場の動き）

USDT・USDC の会員には、ドルの成長だけを出します。
見た目は会員アプリの「2a 篝火の紋」と同じです（`README.md` と `rengoku-tokens.css`）。この画面で新しく使う値は `--rg-w-*` として末尾に足しました。
精度は**高精度（hi-fi）**です。

## 2. ファイル
`design/` にあるのはデザインの見本です。今の Next.js の会員アプリに、部品として作り直してください。
- `Rengoku Wallet.dc.html` … 全体のボード（W1〜W7）
- `Rengoku Wallet Screen.dc.html` … 資産の画面。`scenario` で状態を切り替えます: `btc` / `usdt` / `new` / `doge` / `mismatch`
- `Rengoku Breakdown.dc.html` … 価値の分解の部品（`variant="full"` / `"thin"`）

## 3. 色と言葉の決まり
| 何 | 色 | トークン |
|---|---|---|
| トレードで増えた枚数・トレードの損益（プラス） | 金 `#F2C463`、帯は `#FFE9A8 → #E0A93A` | `--rg-w-trade-text` / `--rg-w-seg-trade` |
| 値上がり益（プラス） | 炎色 `#FF9A5A`、帯は `#FFB070 → #E2602A` | `--rg-w-market-text` / `--rg-w-seg-market` |
| どちらも、マイナスの時 | 青 `#7FB2FF`、帯は青の斜線と 1px の青い縁 | `--rg-w-down-text` / `--rg-w-seg-neg` |
| 元本 | クリーム色の半透明 | `--rg-w-seg-principal` |

**通貨のバッジ**
- 色：BTC `#E8A24A` / ETH `#A3AEE8` / USDT `#4FB894` / USDC `#93A8C6` / 対応していない通貨 `#B9A48F`
- どの通貨も、面は 12〜14%、縁は 40〜50% の透明度
- 形：高さ 22px（一覧の中では 20px）、左右の余白 8px、角丸 4px
- 中身：記号（₿ Ξ ₮ $ Ð）を Saira 700 14px、コードを Cinzel 600 11px・字間 .14em

**言葉**：資料 07 の言葉の決まりのとおりです（財布の通貨・元本・トレードで増えた枚数・値上がり益・期間）。

### W3. 価値の分解（いちばん見せたいところ）
**帯**
- 高さ 30px、角丸 6px、面 `rgba(10,5,3,.6)`、縁 1px `rgba(255,200,61,.18)`
- **元本は帯の 44% に縮めて描く**。左から 20% の位置に、斜めの切れ目（幅 7px、`skewX(-20deg)`、カードの地の色）を入れる
- 帯の上に「元本の長さは縮めて表示しています」（11px）と書き添える
- 残りの 54% に、増減の分を同じ縮尺で描く
- 計算のしかた（P = 元本、t = トレード、a = 値上がり益）:
  - `lo = min(0, t, t+a)`、`hi = max(0, t, t+a)`、`pos(x) = 44% + (x − lo) / (hi − lo) × 54%`
  - 元本は `0 → pos(0)`
  - トレードは `pos(min(0,t)) → pos(max(0,t))`
  - 値上がり益は `pos(min(t,t+a)) → pos(max(t,t+a))`
  - マイナスの部分は、青の斜線を上に重ねる
- **今の価値**の位置 `pos(t+a)` に、白の縦線を引く（2px、帯の上下に 6px はみ出す、`0 0 8px` の光）

**帯の下の一覧**
- 色の四角 10px + 名前 13px + 値（Saira 18px）。行と行の間に 1px の線
- 最後に「今の価値」（明朝 700 14px）+ 値（Saira 26px `#FFF4E2`）
- 例：元本 $1,200.00 / トレードの損益 +$90.00 / 値上がり益 +$64.50 / 今の価値 $1,354.50

**ひとこと**（12px `#C9B8A6`）
- プラス：「トレードの成果 +$90.00 に、相場の値上がり +$64.50 が加わっています。」
- マイナス：「相場の動きで −$25.70 となりました。トレードの成果 +$43.00 はそのまま残っていて、値段が戻れば価値も戻ります。」
  - 責めない・煽らない。トレードの成果を先に、または同じ重さで伝える。「損」「暴落」などの言葉は使わない
- USDT：「ドルのまま運用しているので、トレードの成果がそのまま積み上がります。」

**ドル / 枚数の切り替え**（BTC・ETH の時だけ）
- 右上に小さな切り替え（高さ 24px、選ばれている方は金の面）
- 「枚数」にすると、元本 0.0200 BTC + トレードで増えた枚数 +0.0015 BTC = 0.0215 BTC の 2 つに分ける（値上がり益は入らない）
- その時のひとこと：「この枚数は値段が動いても変わりません」

**動き**
- 画面を開いた 0.12 秒後に、元本 → トレード → 値上がり益の順に、幅 0 から伸びる（各 .9 秒、`cubic-bezier(.2,.8,.2,1)`、0.18 秒ずつずらす）
- 白い縦線は 0.8 秒後にふわっと出る
- 動きを止める設定では、最初から伸びた状態で出す

### W5. 通貨が変わった時のお知らせ・財布の通貨
**仕組み**
- 受け子から届いた通貨が変わったら、自動で新しい期間を始める
- 同時に、通知（とプッシュ通知）を送り、資産の画面の上にお知らせの帯を出す（縁は金、「違う場合 ›」付き）

**通知のカード**
- 見出しの行：WALLET + 「BTC → ETH」のバッジ 2 つ + 時刻
- 題「新しい期間を始めました」（明朝 700 16px）
- 本文「財布の通貨が ETH に変わったので、新しい期間を始めました。元本 0.5000 ETH（= $1,200）」
- 前の期間の成績を 1 行で（面 `rgba(10,5,3,.5)`）
- ボタン 2 つ：「資産を見る」（主役）と「違う場合はこちら」（控えめ）。高さ 44px

**マイページの「財布の通貨」**
- 「自動で見つけた通貨」のカード：バッジは大きめで高さ 28px。「受け子 PC-01 から 10/6 09:12 に見つけました」
- 「手で直す」：4 つの選択肢（USDT / USDC / BTC / ETH）
  - 1 行の高さ 56px、角丸 12px
  - 丸い選択の印 20px + バッジ + 説明 12px。自動で見つけた通貨の行には「自動」の札
  - 選ばれている行：縁 `rgba(255,200,61,.75)`、面 `rgba(60,26,10,.85)`
- 説明文「直すと、その日から新しい期間を始め、運営にも知らせます。これまでの期間の成績は変わりません。」
- 決めるボタン（高さ 60px）
  - 自動の判定と違う通貨を選んだ時だけ炎色になり、押せる（「BTC にする」）
  - 同じ通貨の時は灰色で「自動の判定のまま」

## 5. 必要なデータ
```ts
type Currency = 'USDT' | 'USDC' | 'BTC' | 'ETH' | string; // それ以外は「対応していない通貨」
type Period = {
  index: number; currency: Currency; startAt: string; endAt?: string;
  principalCoin?: number; principalPrice?: number; principalUsd: number; // 入金・出金を足し引きしたもの
  tradeCoin?: number; tradeUsd?: number;             // トレードで増えた枚数 / 損益（ドル）
  marketUsd?: number | null;                         // 値上がり益（USDT・USDC は null）
  endCoin?: number; endPrice?: number; endUsd?: number;
  endReason?: string;                                // 「USDT に変更」など
  series: { date: string; coin?: number; usd?: number }[];
  events: { date: string; kind: 'start' | 'change' | 'in' | 'out'; label: string }[];
};
type Wallet = {
  current: Period; history: Period[]; total: { tradeUsd: number; marketUsd: number; days: number };
  prices: { BTC: number; ETH: number; at: string };
  detected: Currency; declared?: Currency;           // 食い違いの判定に使う
};
```
- 値上がり益 = 今の価値 −（元本 + トレードの損益）
- 枚数は 4 桁で表示（DOGE などは 2 桁）。ドルは 2 桁

## 6. 見本の数字（資料 07 のまま）
- 期間 1：BTC、10/1〜10/5、元本 0.0200 BTC @ $60,000、トレード +0.0015 BTC（+$90）、終わりの価値 $1,354.50、値上がり益 +$64.50
- 期間 2：ETH、10/6〜10/9、元本 0.5000 ETH @ $2,400、トレード +0.0180 ETH（+$43）、終わりの価値 $1,217.30、値上がり益 −$25.70
- 期間 3：USDT、10/10〜、元本 $1,250.00、トレード +$38.00、今の価値 $1,288.00
- 通算：トレード +$171、値上がり益 +$38.80
