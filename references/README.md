# 参考の画面 (star)

同じオーナーが作っているスマホゲーム「star」の画面です。**操作感と部品の形だけ**を参考にしてください。

| ファイル | 見てほしいところ |
|---|---|
| `star/setup-390.webp` | 太い縁の入力欄、太い縁のパネル、下部の大きな板ボタン (使えない状態の灰色)、色の選択のタイル |
| `star/train-390.webp` | 上部 HUD (左の金の「‹ 戻る」板、中央の画面名、右の丸い操作ボタン)、金の縁のお知らせの帯 |
| `star/stable-retired-390.webp` | カードを並べた一覧の作り |
| `star/setup-1280.webp` | PC で開いた時の見え方 |

**取り入れないもの**: 紺と金の配色、馬・競馬場の背景、ゲームの用語。Rengoku は炭・炎・金の配色にします。

star に無く、Rengoku で新しく足すもの: ボタンを押した時に沈む動き、振動、PWA (ホーム画面のアイコン)、下部のタブバー。
