# 06 マスター画面 (運用者向け) — Rengoku デザインへの作り直し

## これは何か
**田辺さん (打ち手) とオーナーの 2 名だけ**が使う操作画面です。田辺さんがライブのバカラを見ながら、
「どの卓で・P か B か・いくら」を押すと、チームの受け子 (メンバーの PC、今 3 台 → 15〜18 台へ) に**同時に BET が配られます**。
会員アプリ (ダッシュボード) の「マスター画面」ボタンから開きます。

- 見た目は会員アプリと同じ **「2a 篝火の紋」** (`design/handoff/rengoku-tokens.css` のトークン・明朝の見出し・Cinzel の英字ラベル・Saira の数字・細い金線・炎のグラデーションのボタン)。
- ただし**操作の速さと読みやすさが最優先**。BET の締め切りまで十数秒しかない中で押す画面です。飾り (火の粉・ゆらぎ) は背景のごく控えめな量にし、操作の邪魔をしない。
- **主に PC (1280〜1920 幅) で使う**。スマホ (390 幅) でも P/B を押せること。

## 画面の部品 (今の画面にあるもの・全部残す)

### A. 上の固定バー
- 今のセッションの損益 (大きく)・選んでいる卓の名前・接続の状態 (マスターがつながっているか)。

### B. 集計のタイル (横一列)
- 稼働中の受け子の数 / セッションの損益 / セッションの勝率 / 1 日の損益 (日本時間) / 1 日の勝率 / 最後の操作 / 選んでいる卓。

### C. 卓の一覧 (約 60 卓)
- 絞り込み (お気に入り・種類)、卓ごとのカード: 卓の名前・出目の罫線 (小さな「ビーズ」の表 = P は青・B は赤・T は緑の丸の並び)・P/B/T の数・連続 (例: B 4 連)・お気に入りの星・ベットの受付中かどうか。
- **卓を押す = 受け子全員がその卓へ移動 (SWITCH)**。今いる卓ははっきり目立たせる。
- ⚠ 罫線の色は**バカラの慣習 (P = 青・B = 赤・T = 緑) を守る**。Rengoku の「赤 = 主役色」とぶつかるので、罫線の中だけは慣習の色、画面の他の場所の赤 (深紅) は装飾と主役のボタンだけに使う。

### D. 選んでいる卓の詳細
- 卓の名前 (大きく)・罫線 (大きく)・P/B/T の数・今の連続・お気に入り。

### E. 操作の面 (いちばん大事)
- **配る先**: 何台に配るか (例: 「配信先 3 台」) と台の名前の一覧。
- **額のチップ**: 「段どおり」(既定・資金管理の段の額) / $1 / $10 / $50 … の 1 回だけの額。選ばれたチップがはっきり分かること。
- **巨大な PLAYER / BANKER ボタン** (TIE は隠しておき、出す設定の時だけ)。押し間違えないよう、左右に大きく離して置く。P = 青系・B = 赤系 (バカラの慣習)。押した瞬間の反応 (沈む・光る) をはっきり。
- **BET の取消** (締め切り 5 秒前まで)・**P ⇄ B の置き換え**・⇄TIE。
- **締め切りまでの残り秒** (受付中・締め切り間近・締め切り)。
- **緊急 STOP** (全受け子を止める・確認つき)。

### F. 受付票 (BET を押した直後に出る帯)
- 受け子ごとに: 成立 (緑) / 不成立 (赤) / 締切待ち (灰) / 応答なし (黄)。名前を色分けして一目で。
- **不成立の理由の詳細** (例:「卓の最低額未満の可能性: Korean Baccarat 2 で $0.20 以下は過去 13 回すべて不成立・$3.00 以上は成立」) を、不成立の台ごとに 1 行。
- 全台の結果がそろうと、合計の損益で一度だけ緑/赤に光る。

### G. 受け子のカード (15〜18 台並ぶ)
- 名前・打ち方 (マーチン / グランドマーチン / SEQ 攻撃 など)・今の段・次の額・今日の損益・前回の BET (面・額・勝ち負け)・今回の BET の状態 (成立・不成立と理由)。
- 状態: オンライン / 止まっている / ロビーに入れない (赤) / Chrome を開き直し中 (黄) / 段のズレの警告。
- **18 台並んでも見渡せる**こと (PC では 3〜4 列、スマホでは縦に並べて畳める)。

### H. 資金管理 (マスター)
- 打ち方 (フラット / ダランベール / マーチンゲール / グランドマーチン)・親の元本・開始額・損切り・利確・止まった時の動き。
- 受け子ごとの設定: 元本・打ち方 (親と同じ / SEQ 攻撃・バランス・守備 / 他)・SEQ の開始額・損切り・利確・卓の上限・有効/無効。
- 「今すぐ反映」と、その前の見比べ (反映すると何が変わるか)。

### I. セッション
- セッション開始 / 終了 (REC)。
- セッション履歴 (折りたたみ): 今のセッション・これまでのセッション (期間・回数・勝敗・勝率・損益・**ローリング**)・内訳 (受け子ごとの打ち方・ローリング・損益÷ローリング)・月ごとの合計。

### J. その他 (折りたたみ)
- 受け子の接続状態の一覧、シグナルの送信履歴。

## 画面の組み立て (提案・変えてよい)
- **PC**: 左 = 卓の一覧 (C)、中央 = 選んでいる卓 (D) と操作の面 (E)・受付票 (F)、右 = 受け子のカード (G)。上に A と B。H・I・J は下に折りたたみ。
- **スマホ**: 上に A、その下に操作の面 (E) と受付票 (F) を最優先。卓の一覧・受け子・資金管理はタブで切り替え。

## 見本の数字 (架空)
- 配信先 3 台: gold / taka / tana。打ち方: gold = SEQ 攻撃 ($1 開始)、taka = マーチン ($0.20 開始)、tana = マーチン
- セッションの損益 +$43.95・勝率 50.5%・1 日 +$20.30・回数 116
- 卓: Baccarat 5 (受付中・残り 9 秒・B 3 連)、Speed Baccarat 15、Korean Baccarat 2 (最低 $1)
- 受付票: 成立 gold ($8.00) taka ($0.40) / 不成立 tana — 卓の最低額未満の可能性
