# 04 PWA のアイコンとスプラッシュ — 最優先

会員はスマホのホーム画面に置いて、アプリのように使う。アイコンはチームの顔になるので作り込む。

## アイコンの方向性
- モチーフ: **炎** と **「煉」の一文字** (または「R」の字) を組み合わせた**オリジナルの紋章**。
- 炭色の地に、炎のグラデーション (金 → 炎 → 深紅) と金の縁。
- 小さく (48px) しても形が分かること。細い線は使わない。
- ⚠ 特定の作品の家紋・刀の鍔・羽織の柄に似せない。

## 書き出す大きさ
| 用途 | 大きさ | 備考 |
|---|---|---|
| `icon-512.png` | 512×512 | 通常 |
| `icon-192.png` | 192×192 | 通常 |
| `icon-maskable-512.png` | 512×512 | 中央 80% に収める (Android の丸・角丸の切り抜き用) |
| `apple-touch-icon.png` | 180×180 | iPhone。角丸は付けない (端末が付ける) |
| `favicon.svg` / `favicon-32.png` | 32×32 | タブ用。単純化した形 |
| `icon-mono.svg` | 単色 | 通知のアイコン用 |

## スプラッシュ (起動画面)
- 炭色の背景の中央に紋章、その下に「RENGOKU」。紋章の下から炎がふわっと立つ (静止画でも成り立つこと)。
- `theme_color`: `#140A06`、`background_color`: `#140A06`。

## 見せてほしいもの
- アイコンの案を 3 つ並べて、それぞれ iPhone と Android のホーム画面に置いた見え方 (ほかのアプリのアイコンと並べて)。
