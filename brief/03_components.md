# 03 部品の決まり

## 大きな板ボタン (いちばん大事)
star の `BigButton` を炎の配色にしたもの。

| 項目 | 値 |
|---|---|
| 高さ | 主要 80〜88px / 小 52px |
| 角丸 | 14px |
| 縁 | 4〜5px の濃い炭色 `#140A06` |
| 面 | 上から下へ 3 段のグラデーション + 上辺に白い光 (`inset 0 3px 0 rgba(255,255,255,.55)`) |
| 影 | 下に硬い影 `0 7px 0 #140A06` + ぼかした落ち影 |
| 文字 | 22px の太字 + 下に 11px の補足 (例:「送金する」/「24 時間以内」) |

色の種類:
- **炎** (主役の操作): `#FFB13D → #FF5A1F → #B3121B`、文字はクリーム。
- **金** (お祝い・確定): `#FFE38A → #FFC83D → #D98A0A`、文字は炭色。
- **炭** (控えめ): 炭の面に金の縁、文字は金。
- **使えない**: 灰色、影なし。

**押した時 (star に無いので新しく作る)**:
- 押した瞬間にボタンが影の深さ分 (7px) 沈み、下の硬い影が消える。80ms。
- 離すと 120ms で戻る。押した瞬間に小さな振動と音 (設定でオンの時)。
- 押せる場所であることが、見た目だけで分かること。

## 上部 HUD
- 左: 金の板のロゴ / 「‹ 戻る」の金の板ボタン。
- 中央: 画面名 (クリーム色の太字)。
- 右: 通知のベル (未読数の赤いバッジ)・メニュー。
- 背景: 炭色の半透明 + 下端に細い金の線。

## 数字のカプセル
- star の通貨カプセルと同じ形 (角丸 12px・太い縁・左に丸いアイコン)。
- 「今日の利益」「残高」「未払い」などを並べる時に使う。数字は Saira Condensed。

## パネル・カード
- 炭色の半透明 (`--rg-panel`)、角丸 16px、2px の縁 (通常は暗い金 `rgba(255,200,61,.35)`、強調は炎色)。
- 見出しは左上に小さな炎のアイコン + 太字。

## お知らせの帯
- star の NoticeBar の形。点滅する小さなランプ + 一行の文。
- 種類で縁の色: メンテナンス = 炎、精算 = 金、成功 = 緑。音は鳴らさない。

## 下部タブバー
- 5 つのアイコン + 文字。選ばれているタブは、炎が灯ったように光る + 少し大きくなる。
- 画面の下の安全領域 (iPhone の下端) を空ける。

## 種類のバッジ (サロン)
- 活動報告 = 金、懇親会 = 炎、メンテナンス = 深紅 + 白文字。角丸 6px、小さめの太字。

## ポップアップ
- 中央に出るカード。出る時に下から少し跳ねて出る。後ろは暗くして火の粉を散らす。
- 入金の確認・紹介報酬の確定など「良いこと」の時だけ、金の火の粉が弾ける演出。

## 読み込み中
- 刀身に炎が走るような細い横長のバー、または篝火が灯る小さなアニメーション。
