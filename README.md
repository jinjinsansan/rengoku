# Rengoku（煉獄）— デザイン資料

チーム専用の会員サイト「Rengoku」の**デザイン用の資料**です。ここにはコードも秘密の値も置きません。

| ファイル | 中身 |
|---|---|
| [`CLAUDE_DESIGN_PROMPT.md`](CLAUDE_DESIGN_PROMPT.md) | Claude Design に渡す指示文 (これを貼る) |
| [`brief/01_concept.md`](brief/01_concept.md) | コンセプト・配色・文字・動き・音 |
| [`brief/02_screens.md`](brief/02_screens.md) | 画面ごとの中身 (TOP・ダッシュボードが最優先) |
| [`brief/03_components.md`](brief/03_components.md) | ボタン・HUD・カードなど部品の決まり |
| [`brief/04_pwa_icon.md`](brief/04_pwa_icon.md) | PWA のアイコンとスプラッシュ |
| [`brief/05_sample_data.md`](brief/05_sample_data.md) | 画面に入れる見本の数字 (すべて架空) |
| [`brief/06_master_screen.md`](brief/06_master_screen.md) | 運用者向けマスター画面の中身 (指示文は `MASTER_DESIGN_PROMPT.md`) |
| [`references/`](references/) | 操作感の参考 (同じオーナーのゲーム「star」の画面) |

## 前提
- 既存の会員サイトと**同じデータ**を、チーム向けに作り直した画面で見せる。
- 見た目と操作感は**スマホのアプリゲーム**。Web サイトらしさは出さない。
- 最優先で作り込むのは **TOP ページ・ダッシュボード・PWA のアイコン**。
- 完成後、運用者向けの「マスター画面」も同じデザインに合わせる (後の段階)。
